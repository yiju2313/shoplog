# 購物記錄 ShopLog

記錄買了什麼、多少錢、在哪裡買、什麼時候過期，並找出每樣東西在哪家店買最便宜。

**線上使用：** https://yiju2313.github.io/shoplog/

## 功能

- **記錄購買**：品名（中／英）、分類、價格、店家、購買日期、到期日
- **單價計算**：填總價＋數量＋單位，自動換算單價（例如 $6.98 ÷ 6 = $1.16/瓶），比價都用單價；秤重商品可直接記每 kg 價格
- **自訂單位**：預設瓶、顆、個、包、捲、根、L、kg、100g，可在新增頁或「設定 → 單位」新增、刪除
- **編輯紀錄**：在商品詳情的「購買紀錄」點任一筆即可修改或刪除
- **從過去紀錄帶入**：輸入品名會自動帶出上次的分類、店家、價格，並提示歷史最低價
- **拍收據辨識**：拍加拿大英文收據，自動辨識商品、價格、店家、日期，翻成中文並估算保存期限，加入前可逐項修改
- **搜尋比價**：用中文或英文搜尋，列出每個商品在各店的最低價排行
- **價格走勢**：商品詳情顯示最低／平均／最高價與歷次購買紀錄
- **首頁排序**：還沒用完、最快到期的排最上面，已用完的在最下面
- **到期提醒**：依已過期、3 天、7 天、30 天內分組；吃完用完打勾就不再提醒（沒有到期日的東西也能打勾）
- **分類管理**：預設食物、飲料、零食、調味料、日用品、清潔用品、個人、寵物，可自行新增或刪除
- **幣別**：新台幣 NT$ ／加幣 CA$
- **從提醒事項匯入**：把 iPhone 提醒事項清單轉成購買紀錄（見下方說明）

## 怎麼記單價

| 情況 | 價格 | 數量 | 單位 | 結果 |
| --- | --- | --- | --- | --- |
| 香蕉牛奶 6 瓶 $6.98 | 6.98 | 6 | 瓶 | $1.16/瓶 |
| 牛奶 4L $6.79 | 6.79 | 4 | L | $1.70/L |
| 白蘿蔔 $2.8/kg | 2.8 | （不填） | kg | $2.8/kg |
| 單一商品 $3.75 | 3.75 | （不填） | （不選） | $3.75 |

同一樣東西請用同一個品名和單位，比價才會放在一起。

## 安裝到手機

1. 用 iPhone 的 Safari 打開上面的網址
2. 點「分享」→「加入主畫面」
3. 從主畫面圖示開啟，會以全螢幕執行

Android 用 Chrome 打開，選單 →「加到主畫面」。

## 收據辨識設定

收據辨識使用 Claude（Anthropic）。

1. 到 [console.anthropic.com](https://console.anthropic.com) 註冊、儲值（最低約 US$5，一張收據約 US$0.01–0.02）
2. Settings → API Keys → Create Key，複製 `sk-ant-` 開頭的金鑰
3. 在 App 的「分類」頁最下方「設定 → 收據辨識金鑰」貼上

建議在 Settings → Limits 設定每月花費上限。

## 從「提醒事項」自動匯入

網頁無法直接讀取 iPhone 的提醒事項，可以用「捷徑」App 一鍵送過來：

1. 打開「捷徑」→ 右上角 ＋ 建立新捷徑
2. 加入動作「**尋找提醒事項**」：條件設為 列表 是 **Food and Life**、已完成 不是 ✓
3. 加入「**合併文字**」：用「新行」合併上一步的提醒事項
4. 加入「**URL 編碼**」：編碼上一步的文字
5. 加入「**URL**」：`https://yiju2313.github.io/shoplog/?import=` 後面接上一步的結果
6. 加入「**打開 URL**」
7. （選用）加入「**將提醒事項標示為已完成**」，匯入過的就不會重複

執行捷徑後 App 會打開，自動把每一項整理成中英名稱、分類、價格、到期日，確認後按「加入」。也可以在「新增 → 從提醒事項匯入」直接貼上文字。

## 資料與隱私

- 所有紀錄和金鑰只存在你自己手機的瀏覽器裡，不會上傳到任何伺服器
- 清除 Safari 網站資料或換手機，紀錄會消失
- 收據照片只會傳給 Anthropic 用於辨識
